# My Closet Search

過去に買ったユニクロ商品（販売終了品も含む）の着回しコーデを、商品番号から探すための自分用アプリ。

## ファイル構成

```
closet-search/
├── index.html    # 画面・デザイン・動作
├── server.js     # 画像検索用の小さなサーバー（Brave Search API を呼ぶ）
├── .env          # APIキー（自分で作る・人に見せない）
├── .env.example  # .env のひな形
├── .gitignore    # .env をGitに入れないための設定
└── README.md     # このファイル（説明と開発メモ）
```

## 使い方

### 初回だけ
1. `.env.example` をコピーして、名前を `.env` に変える
2. `.env` を開き、`ここにAPIキーを貼る` を Brave の APIキーに書き換えて保存

### 毎回
1. VS Codeで `closet-search` フォルダを開く
2. メニュー「ターミナル → 新しいターミナル」で `node server.js` を実行
3. ブラウザで http://localhost:3000 を開く
4. 商品番号（6桁）を入れて「コーデを探す」→ 画像と検索リンクが出る
5. よく探す服は「クローゼットに保存」（ブラウザ内に保存される）
6. 終わったらターミナルで `Ctrl + C` でサーバーを止める

※ `index.html` をダブルクリックで開いても使えるが、その場合は画像検索だけ動かない

## メモ

- 他サイトの画像はコピーせず、リンクで元ページを開く方式にしている（著作権・利用規約対策）
- 保存データはブラウザごと（PCのChromeとスマホは別々）
- 画像検索は1回ごとに Brave の無料クレジットを使う（毎月5ドル分≒約1,000回）。使いすぎは Brave のダッシュボードで確認
- `file://`（ダブルクリック）と `http://localhost:3000` では保存データが別扱いになる
- 写真は長辺400px・JPEGに縮小して localStorage に保存（1枚およそ20〜50KB、全体で約5MBまで）
- WEAR・StyleHint・Instagram は各サイトの検索URLが変わりやすいため、Googleの `site:` 検索で探す形にしている
